# Changelog

## 1.1.0

- Compact desktop layout with a drive strip, folder list, proportional map and largest-file table.
- Original SizeSoul icon, light/dark themes, DPI-aware initial sizing and minimum window dimensions.
- Single-instance Windows mutex; repeat launches activate the existing window.
- Native recycling with system-path, link, attribute and scan-metadata validation.
- Installed-version display and manual stable-release checks against the official repository.
- Per-user Inno Setup installer with a stable app identity, upgrades, downgrade prevention, shortcuts and uninstaller.
- SQLite preferences and bounded history preserved across upgrades/uninstall.
- Public build workflow, checksums, policy tests and security documentation.

## 1.0.0

- Initial Windows scanner, drive information, cancellable isolate, largest files and SQLite history.
